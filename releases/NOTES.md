# Caption Transactions 0.1.0 — experimental independent workbench

An original desktop/browser editor for a small plaintext draft-JSON subset: preview literal caption corrections, inspect UTF-16 style endpoint changes and all shared segment uses, apply one guarded atomic transaction, then save durable undo/redo and deterministic replay.

The included invented scientific draft demonstrates Qbit → qubit across three materials and four segment uses. Tracks, timing values, media, speeds, reference objects and unknown JSON values are preserved by explicit comparisons.

- Windows: extract CaptionTransactions-0.1.0-win-x64.zip and launch CaptionTransactions.exe in a writable folder.
- Offline web: extract the web ZIP and open app.html.
- Source: original MIT code, fixture, tests, exact dependency lock and build/packaging scripts.
- SHA256SUMS.txt lists all archive digests.

This is **not a modified CapCut binary or native compatibility release**. No real CapCut runtime, private draft, media or font was used. Native reopen, rendering, effects and exact-version compatibility remain unverified. The JSON candidate is not a complete native project.

25 core/fresh-process tests, 14 browser checks and packaged executable smoke verification are included as machine-readable evidence in docs. No AI/model or remote editing call is made. See README and NOTICE for the complete preservation contract and limits.
